# playtime limit mod

limits playtime for players individually.\
server side mod!

how it works: starts with an initial time in ticks, then counts up 1 tick in 'allowed' time every 6 server ticks.
players are then checked for whether their playtime exceeds the server's allowed playtime, and if so, are kicked.

the /timeleft command shows how much time you have on the server (non-op cmd)\
the /resetplaytime command takes an optional argument in ticks, and sets everyone's playtime to 0 and the server's back to its default or the argument.
